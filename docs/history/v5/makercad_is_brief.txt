For a long time we have worked on many versions of MakerCAD and its various states and environments. So far we have not come close to the ideal, that changes today with you and I.

V5 is to be based heavily on existing Open Source Projects, SolidCraft (functioning almost exactly as we would want our CAD program to work and deeply similar to Fusion 360) and CADCraft, Which would give us better design possibilities in our sketch environment.

What sets MakerCAD apart from other CAD programs: from the opening screen you choose continue with existing file or create new
Creating a new file starts by asking you questions these are examples and not necessarily the only things asked
	Project name, Describe what you would like to make(the goal: ie Build a dresser to fill the weird cutout in my room),What tools do you have(Basic stuff, a workshop, whatever tools the user has should be able to be listed and cataloged for project reference. It does not ban what the user can make, but it does help keep them focused on achievable project outcomes), What Materials do you have (anything that can be used to create could fall here, its the biggest variable and determines if you are making a chair or a chair shaped blanket. Anything and everything can be listed here, with examples that are useful, like paper mache using recycled paper or paper towels.), How big is it? where does it need to fit? (create dimensioning for the project easy, Also want to use 3d scan data to capture location information, either watertight or point clouds with accurate sizing), When do you need it (create a deadline so that the project has a finish line), what inspires you?(mood board with all the inspiration, notes and project ideas sketched or pasted in, images can also be projected into the project for reference), etc. 

Once this is created then the SolidCraft like Cad Tools appear and begin to guide your use. If scan data was added for the room, the user can edit it to get a clean model or remove unneeded info. The program ideally should be able to detect edges and create a basic model that follows the shapes found, ie the room walls with picture frames, the bed and door all would be shapes created from the data so that the user can realistically build off of the scan or model information. MakerCAD includes an assistant to help the user, help create a sense of scale, provide warnings when needed. Ours is named Sancho after Sancho Panza, who by following Don Quixote helped turn his fantasy into a reality. Sancho will help with that role. If the user is creating a dresser, then the scale is room sized. If smaller, then the workspace is a workbench top equivelent, with a much larger Sancho assisting. Based off the information the user gave, they have materials and tools to choose from. If they have 15 pine 2x4s in 3 foot lengths, the material budget is set, the user can sketch the cuts onto the boards to use the materials they have exactly, or they can model first and the program helps determine how the materials are used. The goal is not to limit creativity but to add context and even restrictions to help spur the creative solution to the problem. If our example Dresser doesnt have enough wood for a specific design, how can it be modified to use what is available? The users would also need to understand that there is always some waste, and this will help visualize it and allow them to compensate. The user continues to develop over time, and at the end of a session they are asked questions about the progress, what worked what failed, and why creating a log that can be later published as a instruction guide or build log. When the user is ready, export documents are created, blueprints, best order of completion, cut templates in scale or with scale ( in case the user has a projector to cast its cut lines), as well as traditional cad file formats.The user can then add videos, images and notes to that show how the actual build went, and since we can scan, compare to our digital version.

The program itself is basically SolidCraft with MakerCad Ideas infused. The Sketch Environment is CADCraft like, expanding on the skectch tools of SolidCraft.Its got a bit dreamy, cartoony color design compared to other CADs, with a Pastel option. It needs to run on Slow older hardware, but It should not be limited only a low grade experience. MakerCAD should be aware of the Hardware it is on, as it is another tool/material the user can use in each project.

Because Low end computers are a potential user base, we want the environments to be modules that can be loaded or unloaded when needed. If the user is creating two items, a pencil sharpener and the box design the sharper would come in, the would have the Solid Modeling environment, Sketch Evironment, Folding Environment, and Animation/physics environment if the sharpener has moving parts, possibly more. These environments would be loaded as needed for the project to keep computer power low, and users can add from all environment options if they choose, such as a future circuit design environment, Fluid dynamics, generative design for removing materials, CNC plotting, CURA like 3D Printing environment, etc. We can create Envrinments that fit our needs, use them when needed, and keep the processes light by only using what we need when we need it. More capable systems can toggle these options to keep all environments active if there is any advantage to this, otherwise lets make it work well on the low end computers and beyond.
